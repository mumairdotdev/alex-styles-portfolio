# Alex Styles Portfolio Website

A modern portfolio website for Alex Styles, a graphic designer showcasing creative projects.

## Project Overview

This portfolio website was designed and developed to showcase Alex Styles' design projects with a clean, professional aesthetic. The site includes sections for About Me, Portfolio, and Contact information, featuring responsive design, interactive elements, and engaging animations.

## Features

- **Responsive Design**: Optimized for all devices from mobile to desktop
- **Interactive Elements**: Portfolio filtering, project modals, custom cursor
- **Animated UI**: Subtle animations to enhance user experience  
- **Accessibility Features**: Includes reduced motion options and semantic HTML
- **Performance Optimized**: Fast loading with efficient CSS and JavaScript

## Technologies Used

- HTML5
- CSS3 (Flexbox, CSS Grid, Animations)
- JavaScript (ES6+)
- Google Fonts
- Font Awesome Icons

## Design Choices

- **Typography**: Combination of Playfair Display for headings and Poppins for body text to create visual hierarchy
- **Color Palette**: Modern scheme with blue as primary color, complemented by dark gray and red accent
- **Layout**: Balanced use of whitespace and grid layouts to create a clean, professional appearance
- **Animations**: Subtle transitions and effects to enhance engagement without being distracting

## Responsive Breakpoints

- Mobile: up to 767px
- Tablet: 768px to 1024px
- Desktop: 1025px and above
